# 🎵 Melo — Retro Music Player

> Built for listening, not skipping.

Melo is a browser-based music player designed around *presence*. 
Drop the tonearm, let the vinyl spin, stay with the track.

**[▶ Live Demo](https://rootnikhil.github.io/melo/)**

---

## Why Melo

Modern players optimise for speed — search, skip, repeat. 
Melo does the opposite. It slows things down and makes 
listening feel intentional again.

---

## Features

- 🎚️ Interactive tonearm — drop it to play, not just press a button
- 📁 Local music library via browser (no uploads, no server)
- ❤️ Liked songs, playlists, recently played
- ⏱️ Sleep timer, playback speed control
- ⌨️ Full keyboard shortcuts
- 💾 Persistent storage via LocalStorage

---

## Stack

Built from scratch — no frameworks, no dependencies.

`HTML5` `CSS3` `Vanilla JS` `Web Audio API` `LocalStorage`

---

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `← →` | Seek |
| `Shift + ← →` | Skip track |
| `↑ ↓` | Volume |
| `L` | Like |
| `M` | Mute |
| `F` | Search |
